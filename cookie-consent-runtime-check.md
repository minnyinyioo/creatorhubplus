# Cookie Consent Runtime Check

The browser runtime exposes the Cookie Consent API and includes `showPreferences` as an available method. Calling `window.CookieConsent.showPreferences()` opened the preference panel successfully. The visible panel includes essential cookies, optional analytics cookies, **Accept all**, **Reject all**, and **Save preferences** controls.

The footer’s **Manage Cookie Settings** button calls this same `showPreferences` method. No consent choice was submitted during verification.
